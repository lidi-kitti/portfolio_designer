# Инструкция по обновлению домена для портфолио

## Подготовка проекта к деплою

### 1. Статические файлы (изображения, иконки и т.д.)

**Важно:** Все статические файлы (изображения, иконки, шрифты и т.д.) должны находиться в папке `public` в корне проекта. 

Файлы из папки `public` автоматически копируются в корень папки `build` при сборке и доступны по абсолютным путям, начинающимся с `/`.

**Пример:**
- Файл: `public/photo.png`
- Использование в коде: `src="/photo.png"` (не `./photo.png`)

### 2. Сборка проекта

Перед деплоем соберите проект:

```bash
npm run build
```

После сборки папка `build` будет содержать готовые файлы для деплоя, включая все файлы из папки `public`.

## Варианты деплоя и настройки домена

### Вариант 1: Vercel (Рекомендуется)

#### Шаги:

1. **Установите Vercel CLI** (если еще не установлен):
   ```bash
   npm i -g vercel
   ```

2. **Войдите в Vercel**:
   ```bash
   vercel login
   ```

3. **Создайте файл `vercel.json`** в корне проекта (для исправления ошибки 404 и указания правильной папки сборки):
   ```json
   {
     "buildCommand": "npm run build",
     "outputDirectory": "build",
     "rewrites": [
       {
         "source": "/(.*)",
         "destination": "/index.html"
       }
     ]
   }
   ```
   Этот файл необходим для:
   - Правильной работы одностраничного приложения (SPA) на Vercel
   - Указания правильной папки сборки (`build` вместо стандартной `dist`)

4. **Деплой проекта**:
   ```bash
   vercel
   ```
   Следуйте инструкциям в терминале.

5. **Настройка кастомного домена**:
   - Зайдите на [vercel.com](https://vercel.com)
   - Откройте ваш проект
   - Перейдите в **Settings** → **Domains**
   - Добавьте ваш домен (например: `yourdomain.com`)
   - Следуйте инструкциям по настройке DNS записей:
     - Добавьте A-запись или CNAME в настройках вашего домена
     - Для корневого домена: `A` запись → `76.76.21.21`
     - Для поддомена: `CNAME` запись → `cname.vercel-dns.com`

6. **Автоматический деплой**:
   - Подключите GitHub репозиторий к Vercel
   - Каждый push в main ветку будет автоматически деплоить проект

### Вариант 2: Netlify

#### Шаги:

1. **Создайте файл `netlify.toml`** в корне проекта:
   ```toml
   [build]
     command = "npm run build"
     publish = "build"

   [[redirects]]
     from = "/*"
     to = "/index.html"
     status = 200
   ```

2. **Деплой через Netlify CLI**:
   ```bash
   npm install -g netlify-cli
   netlify login
   netlify deploy --prod
   ```

3. **Настройка кастомного домена**:
   - Зайдите на [netlify.com](https://netlify.com)
   - Откройте ваш проект
   - Перейдите в **Site settings** → **Domain management**
   - Нажмите **Add custom domain**
   - Введите ваш домен
   - Настройте DNS записи:
     - Для корневого домена: `A` запись → IP адрес Netlify
     - Для поддомена: `CNAME` запись → `your-site.netlify.app`

---

### Вариант 3: GitHub Pages

#### Шаги:

1. **Установите gh-pages**:
   ```bash
   npm install --save-dev gh-pages
   ```

2. **Обновите `package.json`**:
   ```json
   {
     "scripts": {
       "dev": "vite",
       "build": "vite build",
       "predeploy": "npm run build",
       "deploy": "gh-pages -d build"
     },
     "homepage": "https://yourusername.github.io/UX-UI-Designer-Portfolio"
   }
   ```

3. **Деплой**:
   ```bash
   npm run deploy
   ```

4. **Настройка кастомного домена**:
   - Создайте файл `CNAME` в папке `public` (или `build` после сборки)
   - Добавьте в файл ваш домен: `yourdomain.com`
   - В настройках GitHub репозитория:
     - Settings → Pages → Custom domain
     - Введите ваш домен
   - Настройте DNS:
     - `CNAME` запись: `yourusername.github.io`

---

### Вариант 4: Общий хостинг (cPanel, FTP и т.д.)

#### Шаги:

1. **Соберите проект**:
   ```bash
   npm run build
   ```

2. **Загрузите файлы**:
   - Загрузите все файлы из папки `build` на ваш хостинг
   - Обычно в папку `public_html` или `www`

3. **Настройка домена**:
   - В панели управления хостингом настройте домен
   - Убедитесь, что файл `index.html` находится в корневой папке домена

## Настройка DNS записей

### Для корневого домена (example.com):

**Vercel:**
```
Type: A
Name: @
Value: 76.76.21.21
```

**Netlify:**
```
Type: A
Name: @
Value: 75.2.60.5
```

### Для поддомена (www.example.com):

**Vercel:**
```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
```

**Netlify:**
```
Type: CNAME
Name: www
Value: your-site.netlify.app
```

## Проверка после настройки

1. **Проверьте DNS записи**:
   - Используйте [whatsmydns.net](https://www.whatsmydns.net) для проверки распространения DNS

2. **Дождитесь распространения DNS**:
   - Обычно занимает от нескольких минут до 48 часов

3. **Проверьте SSL сертификат**:
   - Большинство платформ автоматически настраивают HTTPS
   - Убедитесь, что сайт открывается по `https://yourdomain.com`

## Обновление существующего домена

Если домен уже настроен и нужно его изменить:

1. **Удалите старый домен** в настройках платформы деплоя
2. **Добавьте новый домен** по инструкции выше
3. **Обновите DNS записи** у вашего регистратора домена
4. **Дождитесь распространения DNS**

## Решение проблем

### Проблема: Сайт не открывается после настройки домена

**Решение:**
- Проверьте DNS записи через `nslookup` или онлайн-инструменты
- Убедитесь, что DNS записи правильно настроены
- Подождите до 48 часов для полного распространения DNS

### Проблема: HTTPS не работает

**Решение:**
- Большинство платформ автоматически настраивают SSL
- Проверьте настройки SSL в панели управления платформы
- Убедитесь, что домен правильно привязан

### Проблема: 404 ошибка на страницах

**Решение:**
- Убедитесь, что настроены редиректы (см. конфигурацию для Netlify выше)
- Проверьте, что `index.html` находится в корневой папке
